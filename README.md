# 2048MCTS
Solving 2048 Using MCTS

## taka_changes branch.
In the taka_changes branch the root directory shows the original implementation where the Wi = total reward collect form child i simulations.

In the `./ratio` directory holds the code where epsilon greedy is implemented with a weighted value based on the empty cells and if the tile is in the corner. This directory contains the MCTS implementation that has achieved a max tile of 2048
